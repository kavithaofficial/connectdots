# ConnectDots

ConnectDots is a premium collaboration-discovery platform designed to help people find the right partners, opportunities, and project teams.

## What this version includes
- Premium landing page
- Login and signup screens
- Dashboard with recommendations and notifications
- Discover page with search and filters
- Projects marketplace
- Messaging experience
- Pricing page
- Profile page
- Admin overview page
- Mock data for a polished product demo

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Tech stack
- Next.js 14
- TypeScript
- Tailwind CSS
- App Router
